## 🧭 문서 명명 규칙 및 관리 체계

문서가 많아져도 1초 만에 원하는 내용을 찾을 수 있도록 다음 3가지 원칙으로 관리됩니다:

1. **파일명 형식**: `docs/history/[3자리번호]_[YYYY-MM-DD]_[핵심주제].md`
   - 예: `001_2026-09-05_랜딩페이지_큐레이션_연동.md`
   - 예: `002_2026-09-06_Hallmark디자인진단_및_CLI패키지매니저_기획.md`
2. **루트 최신 바로가기**:
   - 프로젝트 루트의 `HANDOFF.md`를 열면 항상 **가장 최근 회차의 내용**이 요약되어 있어 빠르게 작업을 이어갈 수 있습니다.
3. **영구 보존**:
   - 이전 대화나 아이디어가 날아가지 않도록 모든 회차 문서는 번호순으로 차곡차곡 누적됩니다.
